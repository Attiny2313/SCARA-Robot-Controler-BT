# 3D printing files

This directory contains printable files used by the SCARA project. Some files are based on third-party designs and therefore keep their original licenses.

## `Parts set.3mf`

The robot mechanical construction is based on the **PyBot SCARA Robotic Arm** by **jjRobots**.

Original project:
- https://www.jjrobots.com/scara-robotic-arm-by-jjrobots/
- https://cults3d.com/en/3d-model/gadget/scara-robotic-arm-open-source-with-control-app

The PyBot design is published under **Creative Commons Attribution-NonCommercial-ShareAlike (CC BY-NC-SA)**. Any geometry originating from or derived from PyBot remains under that upstream license.

Many thanks to **jjRobots** for the original mechanical design and for making the project available to the maker and robotics community.

## `Alternative gripper.3mf`

The alternative gripper is based on **Robot Gripper 9g Micro Servo** by **yisparyan**:

- https://www.thingiverse.com/thing:715525

The original gripper is published under **Creative Commons Attribution (CC BY)**. Attribution to yisparyan and the original Thingiverse design must be retained when redistributing this file or derivatives.

Many thanks to **yisparyan** for sharing the gripper design.
